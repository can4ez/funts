# После полуночи — Правда или действие 18+

Веб-игра 18+ для 2–24 игроков, адаптированная для телефонов. Код проекта опубликован
в этом репозитории, установка не требуется.

**Сайт (после активации GitHub Pages):** https://can4ez.github.io/funts/

## Как запустить локально

Откройте `index.html` в браузере. Игра работает без сборки, бэкенда и обязательного интернета.

## Как работает публикация

Workflow `.github/workflows/pages.yml` тестирует парсер и автоматически публикует
`index.html` на GitHub Pages при отправке изменений в `main`.

Для первоначального включения откройте **Settings → Pages → Build and deployment**
и выберите **Source: GitHub Actions**. Затем вручную запустите workflow во вкладке Actions,
если автоматический запуск не прошёл.

Для GitHub Pages в **приватном** репозитории требуется тариф GitHub Pro/Team/Enterprise.
Если тариф GitHub Free, Pages потребует сделать репозиторий публичным.
Опубликованный Pages-сайт публично доступен даже при приватном репозитории.

# ПОСЛЕ ПОЛУНОЧИ 18+ — Mobile v3

Русскоязычная локальная игра «Правда или действие» для компании **от 2 до 24 взрослых** с отдельным импортёром и дедупликатором колоды.

## Что изменилось в Mobile v3

- **Новая мобильная компоновка:** на телефонах 320–800 px вместо громоздкого колеса и таблицы сразу показывается текущий игрок, прогресс раунда и карточка с выбором «Правда / Действие». На планшетах и ПК сохранён прежний широкий интерфейс.
- **Панель «Компания и очки»:** нажмите на иконку списка рядом с именем активного игрока. Откроется прокручиваемая нижняя панель со всеми участниками, баллами и количеством пропусков. Поддерживается до 24 игроков.
- **Быстрое создание компании:** кнопки добавления одного и сразу четырёх игроков. Лимит 24 игрока и правила командного режима не изменились.
- **Карточки в фокусе:** крупный читаемый текст, понятные основные действия и свободный пропуск; обычные короткие карточки используют нижнюю закреплённую панель действий, длинные — кнопки после полного текста.
- **Удобство на телефоне:** крупные сенсорные элементы, корректная работа при 320/390/430 px, safe area и учёт `prefers-reduced-motion`. Кнопки настроек, завершения и звука доступны из шапки.
- **Без слома логики:** оставлены три режима, 177 оригинальных карточек, 24 события, таймер, пользовательские JSON-колоды, Python-парсер и дедупликация.

Для предпросмотра есть скриншоты `mobile-v3-setup.png`, `mobile-v3-choice.png`, `mobile-v3-card.png`, `mobile-v3-players.png` (вне минимального ZIP-архива).

Тестирование: `python tests/mobile_qa.py` и `python tests/browser_smoke.py` (необходим Playwright + Chromium) и `python -m unittest discover -s tests -p 'test_*.py' -v`.

## Запуск игры

Откройте `index.html` в современном браузере. Устанавливать Python или запускать сервер **для самой игры не требуется**. Введите имена, добавьте/уберите участников, выберите режим и уровень, подтвердите 18+.

- **Классика:** каждый играет за себя, за один круг каждый получает ровно один ход; новый круг со случайным порядком без повторения последнего игрока сразу в начале следующего.
- **Хаос:** то же самое плюс групповое событие после полного круга.
- **Команды:** две равные команды (4, 6, 8 ... 24 игрока), состав: первая половина списка против второй; очки суммируются. При нечётном количестве режим недоступен.
- **Выбор другого участника:** текст `{target}` заменяется именем другого игрока, в командном режиме — случайного товарища по команде (с балансировкой обращений).
- При числе участников больше восьми на *десктопном* круге визуализируются ближайшие восемь, а полный список доступен в прокручиваемом блоке. На телефонах круг заменён компактной карточкой активного игрока, полный список открывается по кнопке.

Есть 177 оригинальных карточек и 24 события, три уровня откровенности, 45-секундный таймер, бесплатный пропуск и опциональные карточки с прикосновениями (по умолчанию отключены). Локальное сохранение идёт в `localStorage` (если его допускает браузер); серверных запросов, аналитики и синхронизации телефонов нет. Для более стабильного сохранения и совместимости с файловой политикой браузера игру можно разместить на статическом HTTPS-хостинге.

### Импорт готовой колоды в браузер

Нажмите **«Свои карточки» → «Импортировать JSON»**, выберите `examples/clean-question-bank.json` или другой JSON банка. Импорт поддерживает массив карточек и объект `{"cards": [...]}`. Нормализованные **точные** повторы с базовыми/уже загруженными карточками не добавляются. Проверка *похожих* формулировок выполняется отдельным CLI-парсером. До 5000 дополнительных карточек, ограничение файла — 3 МБ. Свои карточки можно экспортировать обратно в JSON.

Формат карточки:

```json
{
  "type": "truth",
  "level": 2,
  "text": "Какой комплимент тебе запомнился сильнее всего?",
  "touch": false,
  "source": "my-authorized-dataset",
  "license": "Original"
}
```

`type`: `truth` (правда) или `dare` (действие). `level`: 1, 2 или 3. `touch`: `true` только если контакт сознательно отмечен после ручного просмотра.

## Импортёр и дедупликация (Python 3.10+)

### Установка и запуск

```bash
python -m pip install -r tools/requirements.txt
python tools/question_importer.py \
  --config examples/sources.example.json \
  --existing data/base-question-bank.json \
  --output question-bank.json \
  --report question-report.json
```

В Windows PowerShell выполните команду в одну строку (без `\`), например:

```powershell
python tools/question_importer.py --config examples/sources.example.json --existing data/base-question-bank.json --output question-bank.json --report question-report.json
```

Это запускает **локальный тест**: три придуманных демонстрационных источника (JSON, CSV и HTML). Результат теста на текущем коде: 11 входных записей → 7 уникальных, 4 дубликата. `question-bank.json` загружается в веб-приложение через кнопку импорта.

- `question-bank.json` — готовые чистые карточки для игры;
- `question-report.json` — статистика, список удалённых дублей, похожие пары для ручной проверки, неверные записи и ошибки источников;
- `--existing` — исключить совпадения с уже существующей базой (177 оригинальных карточек);
- `--hard 0.93` — минимальное сходство для автоматического удаления почти одинаковых вопросов;
- `--review 0.83` — порог для ручной проверки потенциальных дублей (они остаются в колоде, пока не решите иначе).

Дедупликация учитывает тип карточки, регистр, `ё/е`, Unicode, знаки препинания, пробелы и близкие формулировки (по RapidFuzz, с запасным вариантом на стандартной библиотеке). Смысловые перефразирования без общих слов могут не находиться — для их поиска потребуется отдельная embedding-модель. Высокопохожие фразы можно удалять автоматически, спорные выводятся в отчёт.

### Как подключить другие сервисы

Редактируйте `examples/sources.example.json` или сделайте отдельный JSON-манифест. Каждый источник может быть локальным `path` или публичным `https://` `url` (массив `urls` также допускается). Тип источника: `kind: "json"`, `"api"`, `"csv"`, `"html"`.

Ключи конфигурации:

| Ключ | Для чего |
| --- | --- |
| `id` | Уникальное имя источника, сохраняется в каждой карточке |
| `record_path` | Массив внутри JSON, например `data.questions` или `messages` |
| `text_field` | Имя текстового поля, например `question`, `prompt`, `content` |
| `type_field`, `level_field`, `touch_field` | Поля типа, уровня, физического контакта |
| `type`, `level` | Значения по умолчанию, если нет полей |
| `filter_field`, `filter_value` | Фильтрация массива, например `role=user` |
| `selectors` | Для HTML: список объектов `{ "selector": ".truth li", "type": "truth", "level": 2 }` |
| `license`, `source_url` | Авторство/лицензия и адрес происхождения данных |
| `approved`, `permission_note` | Обязательная явная авторизация для сетевого источника |

В примере предусмотрен **выключенный** HTTP-адаптер для открытого набора [Hugging Face `chethanyadav/truth-dare`](https://huggingface.co/datasets/chethanyadav/truth-dare) (пометка MIT на странице набора). Перед включением убедитесь в условиях реального использования, затем поставьте `enabled: true`. Данные из этого источника **англоязычные** — парсер их не переводит. Для отдельных сервисов с JS-рендерингом потребуется разрешённый официальный API или экспорт, поскольку модуль не запускает браузер и не обходит защиту сайта.

### Авторские права и ограничения обхода

**Не загружайте колоды чужих коммерческих игр без лицензии/разрешения.** Например, в правилах `truthordaregame.net` и `truthdare.me` сбор/скрейпинг карточек запрещён. Поэтому они намеренно не включены в конфигурацию. Открытый URL сам по себе не означает разрешения на копирование.

Сетевой парсер требует `approved: true`, `license`, `permission_note`; проверяет `robots.txt`, уважает `crawl-delay`, делает паузу между запросами, ограничивает ответ 2 МБ, отказывается от HTTP, внутренних IP и перенаправлений на сторонний домен. Это *дополнительные* меры, но они **не заменяют проверку Terms of Service и авторских прав человеком**. Парсер не содержит авторизации, обхода CAPTCHА, антибота или платного доступа. Автоматической модерации контента, проверки качества переводов и согласия на прикосновения также нет.
