# После полуночи — Правда или действие 18+

Мобильная браузерная игра для компаний от 2 до 24 совершеннолетних игроков.

## Быстрое скачивание

Скачайте файл [after-midnight-mobile-full.zip](./after-midnight-mobile-full.zip) (на странице файла нажмите **Download raw file**) или используйте **Code → Download ZIP**.

После распаковки откройте `posle_polunochi/index.html` в браузере. Для игры сервер и установка зависимостей не нужны.

## Состав проекта

- Адаптивный интерфейс игры для смартфонов и компьютеров.
- Режимы «Классика», «Хаос» и командная игра, уровни откровенности, очки и пропуски.
- Импорт собственных вопросов и действия по взаимному согласию.
- Python-парсер JSON/CSV/HTML с проверкой источников и дедупликацией.
- Примеры конфигураций, отчёты импорта и тесты.

Полная документация доступна внутри архива в `posle_polunochi/README.md`. Используйте только те сторонние источники, для которых у вас есть право на импорт содержимого.
